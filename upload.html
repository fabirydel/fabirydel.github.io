Browser not supported

This wizard uses the File System Access API to write images and files directly into your repo. That requires a Chromium-based browser (Chrome, Edge, Brave, Arc) on localhost.

Open this page in Chrome via http://localhost:4000/upload while running bundle exec jekyll serve.

Step 1 — Point to the site folder

Pick the root of your fabirydel.github.io repo. The wizard needs read/write access to write images and update files.

It checks for _locations/, _countries/, _data/locations_per_country.yml, and images/ inside the folder you choose.

Step 2 — Add your photos

Drop the full-size photos here, or click to pick them. They'll be resized client-side to full (max 1300px), thumb (max 400px), and blur (max 30px) — same as makethumbnails.com.
